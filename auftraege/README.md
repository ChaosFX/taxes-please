# Arbeitsaufträge

Hier legt der Claude-Chat Aufträge für Claude Code ab, eine Datei pro Auftrag: `NN-kurztitel.md` (zum Beispiel `01-animationen.md`).

Jeder Auftrag enthält: Ziel, betroffene Dateien, Abnahmekriterien als Checkliste und was nicht dazugehört. Claude Code arbeitet sie in Reihenfolge ab und berichtet pro Auftrag.
